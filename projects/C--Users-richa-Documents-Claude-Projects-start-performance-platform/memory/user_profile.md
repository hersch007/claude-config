Richard Brashear is the founder of Start Performance (startadvertising.com). He builds white-label WordPress plugins for clients (chatbots, quote builders, ticket systems) and is now consolidating those tools into a unified commercial platform called Start Performance Platform.

He works at the product/architecture level — defining systems, Cores, and commercial structure — rather than writing code himself. Claude Code is being used as the primary development partner.

He thinks in product terms (Cores, modules, AI add-ons, pricing tiers) and has a clear vision for the commercial model. Architecture reviews and build plans should match that vocabulary.
