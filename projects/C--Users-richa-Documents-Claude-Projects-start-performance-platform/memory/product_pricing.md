## Pricing Model (as of 2026-08-17)

### Setup — One-Time, Scales with Core Count
| Cores Selected | Setup Fee |
|---|---|
| 1 Core | $1,799 |
| 2 Cores | $2,500 |
| 3 Cores | $3,200 |
| 4 Cores | $4,000 |

Setup flexes by total core count — not a flat fee plus add-ons. More cores = higher setup (reflects implementation complexity).

### Monthly — Per Function
| | Monthly |
|---|---|
| First Function | $299 |
| Each Additional Function | $99 |

Monthly pricing is per function across the whole client, not per core.

**Why:** Low entry point ($299/mo) encourages adoption. $99/mo per additional function is nearly frictionless to expand — clients add functions without a second sales conversation.

### Performance Cores & Their Functions
- **Sales Core:** Estimates, Proposals, Quotations, Contracts, Marketing Support
- **Operations Core:** Onboarding, Scheduling, Workflow Mgmt, Task Tracking
- **Service Core:** Ticket Mgmt, Service Scheduling, Customer Portal, Customer Calculator
- **Finance Core:** Ecommerce, ERP Interface, Accounting Interface, Inventory Interface

### Add-Ons (still exist, pricing TBD in new model)
- CRM, Intelligence, AI Chat, Knowledge Core — attach to any core

## Example Math
- 1 core, 1 function: **$1,799 setup / $299/mo**
- 1 core, 4 functions: **$1,799 setup / $596/mo**
- 2 cores, 6 functions: **$2,500 setup / $794/mo**

## Naming
- Base product: **Foundation** ($99/mo, no customization, no setup)
- Performance modules: **Performance Cores** (Sales Core, Service Core, etc.)

## Sales Pitches
- **No CRM:** "Start with Foundation. Add the Performance Cores your business needs."
- **Has HubSpot/Salesforce:** "Keep your CRM. Add the performance layer it's missing."

## Key Rules
- Clients with existing CRM skip Foundation, go straight to a Performance Core
- Foundation has NO customization
- Government Service Core is a **separate product** — not part of this model
- A pricing calculator spreadsheet exists at `C:\Users\richa\Downloads\SP_Pricing_Calculator.xlsx` with two tabs: individual client configurator + revenue model with existing customers and 3 what-if scenarios

## Viability Notes
- Setup fees may not fully cover implementation at scale — worth monitoring as client count grows
- Monthly revenue per client is modest ($299–$794/mo typical); model is volume-dependent
- The $299 → $99 jump on functions needs a clear explanation in sales conversations
