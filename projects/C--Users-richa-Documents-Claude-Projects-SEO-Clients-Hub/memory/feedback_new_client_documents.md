When onboarding a new SEO client, always create exactly two documents in the correct folder under clients/:
1. `CLIENT-BRIEF.md` — short reference card (see existing examples for format)
2. `[INITIALS]-SEO-AUDIT-[YYYY-MM-DD].md` — full 11-section audit report using the SEO-REPORT-TEMPLATE.md format

**Why:** User explicitly corrected me twice for creating files with wrong names (brief.md, audit-2026-06-04.md) instead of following the established naming convention. The correct names match all other clients in the project.

**How to apply:** On every new client onboarding, check clients/ folder for an existing example before creating files. Match the exact filename format. Never use generic names like "brief.md" or "audit.md".
