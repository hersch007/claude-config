At the start of every new session, before writing any posts, always ask:

"Before we start — what's the weekly brief?

Example format:
Monday: lifestyle
Tuesday: attic ventilation, product shot
Wednesday: AEROPRO video caption
Thursday: kitchen remodel
Friday: Homey fun post
Default image style: industry / lifestyle / product
Default caption length: short (4 lines) unless noted"

**Why:** The first session ran long with multiple revision rounds because topic, image style, and caption length weren't established upfront. A 30-second brief at the start cuts session length in half.

**How to apply:** Every session. No exceptions. Ask for the brief before generating the first post.
