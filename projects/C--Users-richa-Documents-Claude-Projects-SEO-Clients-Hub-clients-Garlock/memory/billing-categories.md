The user logs time in **15-minute (0.25) increments** across **9 work categories**. Hours live ONLY in the user's timesheet — NEVER put hour values on any tracker/document (see [[client-brand-name]] project rules). In the Excel tracker these appear as **label columns X–AF** (checkmark = category touched this page), NOT hours ("Option B").

The 9 categories:
1. **SEO Research** — keyword research, crawls, page discovery, gap analysis, GSC/GA, NAP verification
2. **AISEO / SEO** — producing on-page assets: titles, metas, alt text, H1 recs, keyword mapping
3. **Schema Development** — building & validating JSON-LD
4. **SEO Content Creation** — brand-NEW content (new page copy, articles, FAQ sets)
5. **SEO Content Addition** — adding copy to an EXISTING page (expand thin section, FAQ block)
6. **Web Pages Copy** — general website copywriting (headlines, body, CTAs, messaging)
7. **Web Updates** — implementing SEO changes in HubSpot (paste titles/metas, insert schema, fix H1s)
8. **SEO Tracking / HubSpot Updates** — maintaining tracker & status records; **client-billable**
9. **Web Graphics Refresh** — swapping/fixing/refreshing images (writing alt text stays in #2 AISEO)

Decision rules (avoid double-counting): rankings/keyword copy → #4/#5; general messaging → #6. Changing live page → #7; updating tracker → #8. Writing alt text → #2; swapping the image → #9.

**Working agreement:** when the user gives a project + hours, I break it across these categories, tell them **which line items are billable vs non-billable**, and track billing status (billed / to-bill / date). Default per-page splits: location/product page ≈ 1.0 hr = Research 0.25 + AISEO 0.25 + Schema 0.25 + Web Updates 0.25 (Research often batched once per sweep).
