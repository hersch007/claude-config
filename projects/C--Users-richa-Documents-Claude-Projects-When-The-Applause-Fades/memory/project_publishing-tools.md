The user uses **Atticus** as their book formatting and publishing software — formats the manuscript and preps it for Kindle/KDP. Atticus only exports PDF, not DOCX.

**Workflow:** User applies every fix in BOTH places — Atticus (publishing master) and the DOCX files (backup/archive). The compiled DOCX (`when-the-applause-fades_COMPILED.docx`) and individual chapter DOCXs are maintained as the only full editable backup.

**Why:** Atticus can't export DOCX, so the DOCX files are the only editable archive of the manuscript.
**How to apply:** Continue updating both the chapter DOCX and compiled DOCX for every fix. User manually mirrors each change in Atticus.
