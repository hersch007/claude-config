Project "When the Applause Fades" is a contemporary romance novel.

**Why:** User wants a professional, organized repository for the full lifecycle of writing and publishing a debut indie romance novel.

**How to apply:** When helping with any task in this project, files should go in the appropriate subfolder per the structure below. Never overwrite files — always version with draft numbers or new filenames. Ask before deleting or moving anything.

## Folder conventions

- `manuscript/` — active working drafts (chXX_draftN.docx)
- `approved-manuscript/` — locked, approved chapter versions
- `canon/` — locked story facts, continuity log
- `editorial-feedback/` — editor and CP notes, response docs
- `characters/` — character profiles (use `character-template.md`)
- `timeline/` — chapter beat sheet (`chapter-beats.md`), story calendar
- `lyrics/` — original song lyrics (use `lyrics-template.md`)
- `marketing/` — blurbs, comp titles, pitch copy
- `website/` — author website copy, press kit
- `social/` — content calendar, captions
- `beta-readers/` — tracker, reader guidelines
- `kdp/` — KDP metadata, upload checklist
- `launch/` — launch plan, ARC tracker
- `email/` — newsletter sequences, reader magnet
- `assets/` — cover art, author photos, branding
- `archive/` — cut scenes, retired drafts (never delete)
- `research/` — industry and location research notes
