Do not reference GroupRB or richard@grouprb.com anywhere in client deliverables, unless the specific context calls for a different one of Richard's business entities.

Do not assume Start Performance there — always ask which provider applies (see [[feedback-seo-provider-always-ask]]). This memory's "default to Start Performance" rule still applies to client-facing work outside that pipeline (manuals, guides, plugin fields, etc.).
