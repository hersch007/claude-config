For Fruth Custom Packaging SEO work logged in [[project-fruth]]'s WORK-LOG.md, Richard bills in **15-minute increments** — hours should always be a multiple of 0.25 (0.25, 0.50, 0.75, 1.00, 1.25, ...), not arbitrary decimals like 0.10 or 0.15.

Richard wants each page's work **split into separate line items by category**, not lumped into one "content + FAQ" number. Confirmed 2026-09-14 (Cushion Packaging Barrier Film) — the categories, and a reasonable per-page default split, are:

| Category | Default hours | Covers |
|---|---|---|
| SEO Research | 0.25 | Buyer-intent keywords/applications for that page |
| Content Dev | 0.50 | Body copy expansion (~400-600 words) |
| FAQ Dev | 0.25 | The FAQ questions + answers |
| Schema Dev | 0.25 | Structuring the JSON-LD (FAQPage/Product/etc.) |
| AISEO | 0.25 | AI-content-expansion framing pass — distinct from traditional SEO Research |
| Implementation | 0 until actually pasted live in HubSpot and verified | Log as its own line, separately, once done — historical rate ~0.75-1h (see [[feedback-dont-ask-billing]]) |

Dev-only total for a typical single page: **~1.50h**, across 5 line items — not one.

**Why:** Richard explicitly rejected a single lumped 1.25h "content + FAQ" line and asked for research/content/FAQ/schema/AISEO/implementation to each be their own row.

**How to apply:** When logging any Fruth WORK-LOG.md hours for a page, write 5 separate rows (research, content, FAQ, schema, AISEO) using the defaults above unless the page's actual scope clearly warrants more/less, plus a 6th "Implementation" row logged as 0/not-done until it's actually live. Same "don't ask, just apply" spirit as [[feedback-dont-ask-billing]] (CPFlex/Garlock) — a different client, same underlying preference not to be asked about billing mechanics repeatedly.
