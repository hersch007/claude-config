As of 2026-08-16, the project is a commercial Steam game (premium, ~$6–10, no microtransactions), aimed explicitly at being a strong seller.

**Direction chosen: "Sorting + conspiracy."** The player classifies items/records for an agency; the items carry the story; the categories turn sinister. Reference points: Papers Please meets *Librarian: Tidy Up the Arcane Library*.

**Key reference:** [Librarian: Tidy Up the Arcane Library](https://store.steampowered.com/app/4197610/) — $5.99, released 2026-04-30, ~14.7k reviews at 93% positive, solo/small indie (ArtRising). First-person, sort 3,072 books by title and cover onto shelves; unlocks include Auto-Shelving.

**Why sorting games suit Richard specifically:** content is *data*, not hand-authored levels — a book/item list is three columns (name, category, art style) and the game generates the mess. This avoids the content burden that kills solo cozy projects.

**Superseded:** an earlier abstract resource-management prototype (delegate life tasks to an AI, autonomy meters, CONTINUITY conspiracy) is at `prototype.html`. It was rejected because the core verb was invisible — the game could not be understood from a screenshot. Its delegation-vs-autonomy tension may still return as an optional automation layer, but only attached to a visible verb.
